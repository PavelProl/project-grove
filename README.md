# project-grove — «Роща»

Фронтенд сайта реальной базы отдыха у озера Парное в Красноярском крае. Посетитель может посмотреть дома и фотографии, найти базу на карте и связаться с владельцами по телефону или в WhatsApp.

[Открыть демо](https://project-grove.netlify.app/) · [Репозиторий](https://github.com/PavelProl/project-grove)

## Возможности

- Главная и страницы домов.
- Анимированное раскрытие карточки в страницу дома и возврат с восстановлением прокрутки и фокуса.
- Фотогалереи с полноэкранным просмотром, кнопками, клавиатурной навигацией и свайпами.
- Карта, маршрут, ссылки звонка и WhatsApp с названием выбранного дома.
- Адаптивная вёрстка, упрощение анимаций при соответствующей настройке устройства и звуки природы по желанию.

## Реализация

React, TypeScript, Vite, React Router, GSAP Flip и CSS Modules. Для проверок используются ESLint, Prettier и Playwright.

Приложение работает без бэкенда и базы данных. Данные домов и контакты хранятся отдельно от компонентов. Смена маршрута согласована с анимацией: приложение сохраняет исходный экран до завершения перехода, управляет прокруткой и фокусом. Полноэкранный просмотр фотографий блокирует прокрутку фона и возвращает фокус после закрытия.

Лицензии шрифтов и CC0-аудио включены в проект.

## Локальный запуск

Требуется Node.js 22.22+ в ветке 22 либо Node.js 24+.

```bash
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173. Страницы домов: `/houses/large-log-house`, `/houses/medium-house`, `/houses/small-house`.

## Проверки

```bash
npm run typecheck
npm run lint
npm run format:check
npm run build
```

Браузерные проверки запускаются отдельно командой `npm run test:e2e`; они не входят в сборку и не запускаются сами при работе агента. Требуется установленный Google Chrome. Playwright проверяет переходы, галереи и другие сценарии на десктопе и в эмуляции телефона. Эмуляция не заменяет реальное устройство. Порядок выбора проверок — в [AGENTS.md](AGENTS.md#границы-и-сдача).

Пример выборочного запуска с одним процессом:

```bash
npm run test:e2e -- tests/navigation.spec.ts --project=mobile --workers=1
```

Просмотр production-сборки после `npm run build`: `npm run preview`. Netlify автоматически собирает `main` командой `npm run build` и публикует `dist`; прямые адреса страниц поддерживаются SPA fallback.

## Статус и ограничения

Демонстрационная версия сайта. Обложки сгенерированы и явно обозначены как концепции; фотографии в галереях предоставлены владельцем.

Оптимизация изображений и скорости загрузки, а также окончательная проверка последних исправлений на реальном телефоне остаются в плане. Индексация намеренно отключена. Цены, вместимость, условия проживания, юридические сведения и права на материалы требуют подтверждения перед запуском для гостей. Выбор дат, новые секции главной и обновление материалов пока не реализованы; автоматическое бронирование и чат-бот также отсутствуют.
